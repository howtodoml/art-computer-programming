# TAOCP Vol. 1, Section 1.1, Exercise 6 [20]

**Problem (paraphrased).** Let T_n be the average number of times step E1 runs when n is fixed and m varies over all positive integers. Find T_5.

## Answer

T_5 = 13/5 = **2.6**

## Why only five cases matter

The first pass through E1 sets r to m mod 5. After that, E3 sets m ← 5 and n ← r. From then on the algorithm only sees 5 and r. So the number of E1 steps depends only on m mod 5.

As m runs over the positive integers, the five residues 0, 1, 2, 3, 4 each come up equally often. The average over all m is therefore just the average over one value from each class. Take m = 1, 2, 3, 4, 5.

## The five cases

Each line is one E1 step, written as m = q × n + r.

**m ≡ 0 (e.g. m = 5)**: 1 step
```
5 = 1 × 5 + 0
```

**m ≡ 1 (e.g. m = 1)**: 2 steps
```
1 = 0 × 5 + 1
5 = 5 × 1 + 0
```

**m ≡ 2 (e.g. m = 2)**: 3 steps
```
2 = 0 × 5 + 2
5 = 2 × 2 + 1
2 = 2 × 1 + 0
```

**m ≡ 3 (e.g. m = 3)**: 4 steps
```
3 = 0 × 5 + 3
5 = 1 × 3 + 2
3 = 1 × 2 + 1
2 = 2 × 1 + 0
```

**m ≡ 4 (e.g. m = 4)**: 3 steps
```
4 = 0 × 5 + 4
5 = 1 × 4 + 1
4 = 4 × 1 + 0
```

## Average

(1 + 2 + 3 + 4 + 3) / 5 = 13/5 = 2.6
