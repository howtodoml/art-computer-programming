# TAOCP Vol. 1, Section 1.1, Exercise 8 [M25]

**Problem (paraphrased).** Write an effective formal algorithm, in the θ_j, φ_j, a_j, b_j form of Eqs. (3), that computes gcd(m, n) for positive integers m and n. The input is the string aᵐbⁿ: m copies of the letter a followed by n copies of b. Keep it as simple as you can. The hint is to follow Algorithm E but use subtraction in place of division: r ← |m − n|, n ← min(m, n).

## How the formal machine works

The state is a pair (σ, j): σ is a string and j is a step number. Step j has four parts: θ_j, φ_j, a_j, b_j. When we're at step j:

- If θ_j occurs somewhere in σ, replace its leftmost occurrence with φ_j and go to step b_j.
- If θ_j doesn't occur, leave σ alone and go to step a_j.

Step N is the halting step. The empty string occurs in every string, at the far left, so a step with empty θ always "succeeds" and just inserts φ at the front.

## The algorithm

Alphabet {a, b, c}, N = 5. The answer is the string a^gcd(m, n).

| j | θ_j | φ_j | a_j (not found) | b_j (found) | what it does |
|---|-----|-----|-----|-----|--------------|
| 0 | ab  | (empty) | 2 | 1 | Delete one a and one b, or go to 2 if none of either is left |
| 1 | (empty) | c | 0 | 0 | Put a c at the far left, go back to 0 |
| 2 | a   | b   | 3 | 2 | Turn every leftover a into b |
| 3 | c   | a   | 4 | 3 | Turn every c into a |
| 4 | b   | b   | 5 | 0 | If any b is left, start a new round; otherwise stop |

## Why it works

Start a round with the string aᵐbⁿ, with m, n ≥ 1.

**Steps 0 and 1.** The only place "ab" occurs is where the a's meet the b's. Step 0 deletes that pair, and step 1 records it as a c at the front. After k trips the string is cᵏ aᵐ⁻ᵏ bⁿ⁻ᵏ. This stops when the a's or the b's run out, which happens when k = min(m, n). Then the string is

c^min(m,n) followed by |m − n| letters, all a's or all b's.

**Step 2** turns any a's that are left into b's. Now the string is c^min(m,n) b^|m−n|.

**Step 3** turns the c's into a's. Now the string is a^min(m,n) b^|m−n|.

That's the input format again, with new values m′ = min(m, n) and n′ = |m − n|. Those are exactly the hint's n and r, moved into place the way E3 moves them.

**Step 4** checks for b's. If there are some, n′ > 0, and we go back to step 0 for another round. If there are none, n′ = 0, and we stop. The string is then a^m′ with m′ = min(m, n), and min(m, n) is the gcd at that point, because m = n when |m − n| = 0.

## Correctness and termination

Each round replaces (m, n) by (min(m, n), |m − n|). That doesn't change the gcd, since any number that divides two numbers also divides their difference, and the other way round. So the gcd stays the same from round to round.

The algorithm stops because m + n goes down. The new total is min + |m − n| = max(m, n), which is less than m + n since both are at least 1. Inside a round, every loop either shortens the string (step 0) or uses up an a or a c (steps 2 and 3), so each round is finite too. When it stops, n′ = 0 and the string is a^gcd.

## Why this counts as effective

Each step only looks for a fixed short string and replaces it with another fixed short string. That's the kind of operation the text accepts as effective. There's no division, no arithmetic, and no counting.

## Example: m = 6, n = 4

Each line shows the string at the start of a round.

```
aaaaaabbbb      (6, 4)
aaaabb          (4, 2)
aabb            (2, 2)
aa              (2, 0)  stop
```

The result is aa, and gcd(6, 4) = 2.
