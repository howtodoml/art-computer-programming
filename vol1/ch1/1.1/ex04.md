# TAOCP Vol. 1, Section 1.1, Exercise 4 [16]

**Problem (paraphrased).** Find gcd(2166, 6099).

## Answer

**57**

## Working

Run Algorithm E with m = 2166 and n = 6099. Each line is one pass through E1, written as m = q × n + r.

```
2166 = 0 × 6099 + 2166
6099 = 2 × 2166 + 1767
2166 = 1 × 1767 +  399
1767 = 4 ×  399 +  171
 399 = 2 ×  171 +   57
 171 = 3 ×   57 +    0
```

The first line has m < n, so the remainder is just m, and E3 swaps the two values. That's the extra pass described in exercise 2.

The remainder hits 0 on the sixth pass, while n = 57. So the gcd is 57.

## Sanity check

2166 = 57 × 38 and 6099 = 57 × 107. Since 38 = 2 × 19 and 107 is prime, 38 and 107 share no factor. So 57 really is the greatest common divisor, not just a common one.
