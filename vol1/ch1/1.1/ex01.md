# TAOCP Vol. 1, Section 1.1, Exercise 1 [10]

**Problem (paraphrased).** Using only replacements of the form `x ← y`, rotate four variables so that (a, b, c, d) end up holding the original values of (b, c, d, a). Use as few replacements as you can.

## Solution

Save `a` in a spare variable, shift everything left by one, then put the saved value into `d`:

```
t ← a
a ← b
b ← c
c ← d
d ← t
```

That's five replacements.

Trace with a = 1, b = 2, c = 3, d = 4:

| step    | a | b | c | d | t |
|---------|---|---|---|---|---|
| start   | 1 | 2 | 3 | 4 | – |
| t ← a   | 1 | 2 | 3 | 4 | 1 |
| a ← b   | 2 | 2 | 3 | 4 | 1 |
| b ← c   | 2 | 3 | 3 | 4 | 1 |
| c ← d   | 2 | 3 | 4 | 4 | 1 |
| d ← t   | 2 | 3 | 4 | 1 | 1 |

The order matters. Each step overwrites a variable whose old value has already been copied somewhere safe. `a ← b` is fine because `t` holds the old `a`. `b ← c` is fine because `a` now holds the old `b`, and so on down the line.

## Why five is the minimum

All four of a, b, c, d must change, so each one is the target of at least one replacement. That's four already.

Now look at the first replacement whose target is one of a, b, c, d. Call it `x ← y`. Just before it runs, x still holds its original value, and nothing else does: no earlier step wrote to a, b, c or d, and if an earlier step copied x into a spare variable, that copy already counts as an extra replacement. The original value of x is needed later, because the rotation moves it into some other variable. So if no copy exists, `x ← y` destroys a value we still need.

The copy has to go into a variable outside a, b, c, d, so it costs one more replacement. That gives at least 4 + 1 = 5, and the sequence above uses exactly five.

This matches the m, n swap from the text. A swap is a cycle of length 2 and takes 3 replacements. A cycle of length k takes k + 1 replacements by the same argument.
