# TAOCP Vol. 1, Section 1.1, Exercise 2 [15]

**Problem (paraphrased).** In Algorithm E (Euclid's algorithm), show that m > n whenever step E1 begins, except possibly the first time.

## Proof

The only way to reach E1 a second time is from step E3. So look at what holds when E3 runs.

E3 comes right after E1 and E2. Neither of those changes m or n. E1 sets r to the remainder of m divided by n, so 0 ≤ r < n. E2 didn't stop the algorithm, so r ≠ 0. Together that gives 0 < r < n.

E3 then sets m ← n and n ← r. Write m′ and n′ for the new values. Then m′ = n and n′ = r, and since r < n we get m′ > n′.

The algorithm goes straight from E3 back to E1 with nothing in between. So every time E1 begins after the first time, m > n. ∎

## The first time

The first time E1 runs, m and n are whatever was passed in, so m ≤ n is possible.

- If m = n, then r = 0 and the algorithm stops right away with answer n.
- If m < n, then r = m. E3 sets m ← n and n ← m, so the first pass just swaps the two values. From then on m > n.

So handing in m < n only costs one extra pass through the loop.

## A side result

The same proof shows n′ = r > 0. So n is always a positive integer when E1 begins, and the division in E1 is always defined.
