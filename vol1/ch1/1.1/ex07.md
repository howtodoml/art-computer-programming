# TAOCP Vol. 1, Section 1.1, Exercise 7 [HM21]

**Problem (paraphrased).** Fix m and let n range over all positive integers. Let U_m be the average number of times step E1 runs in Algorithm E. Show that U_m is well defined, and find how it relates to T_m from exercise 6.

## Answer

U_m = T_m + 1.

## What "average over all n" means

There are infinitely many n, so the average has to be a limit:

U_m = lim (N → ∞) of (1/N) × [C(m, 1) + C(m, 2) + … + C(m, N)]

where C(m, n) is the number of E1 steps on input (m, n). Saying U_m is well defined means this limit exists.

## The key step: n > m costs one extra pass

Suppose n > m. The first E1 step divides m by n. Since m < n, the remainder is r = m, which isn't 0 because m is positive. So E3 runs and sets m ← n, n ← m. The algorithm is now running on (n, m), exactly as if it had started there. So

C(m, n) = 1 + C(n, m)  when n > m.

From exercise 6, C(n, m) depends only on n mod m. Write f(j) for its value when n mod m = j, for j = 0, 1, …, m − 1. By definition, T_m is the average of these m values:

T_m = (f(0) + f(1) + … + f(m − 1)) / m.

## The limit exists, and equals T_m + 1

Split the sum at n = m.

The terms with n ≤ m are a fixed, finite set. Call their total A. It doesn't depend on N, so A/N → 0.

Now take the terms with m < n ≤ N. Each is 1 + f(n mod m). Cut this range into complete runs of m consecutive values, plus at most one partial run at the end. Each complete run hits every remainder 0, …, m − 1 once, so it adds up to m + m·T_m = m(1 + T_m). There are about (N − m)/m complete runs. The partial run has fewer than m terms, each at most 1 + max f. That's a bounded amount, call it B, which doesn't depend on N.

Putting it together:

(1/N) × sum = (1/N) × [A + k·m·(1 + T_m) + (something between 0 and B)]

where k = ⌊(N − m)/m⌋. As N → ∞, A/N → 0, the leftover/N → 0, and k·m/N → 1. So the limit exists and equals 1 + T_m. ∎

## How U_m relates to T_m

U_m = T_m + 1. The extra 1 is the wasted first pass when m < n, the one that just swaps the two numbers (see exercise 2). Almost every n is bigger than m, so that pass shows up in the average with weight 1.

For example, T_5 = 13/5 from exercise 6, so U_5 = 18/5 = 3.6.
